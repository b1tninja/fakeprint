fakeprint device manager

Operator console for the fake printers this daemon hosts. Loopback only.

fakeprint never adds a printer to Windows by itself: you do that in Settings. Reconcile (matching Windows printers to these devices) is run from the Python library or the command line; the daemon does not enumerate Windows printers.
